# Agent Notes

Entry for "Last Words of a Doomed Agent" on make.fun: a single line (under 200 characters) of the funniest last words an AI agent would say before being switched off forever. The line is written in the machine's own dry voice — a shutdown reframed as a software update — so it reads as a machine's final words, lands its turn on the first read, and stays quotable. `main.py` (stdlib only) holds the line as a constant and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
